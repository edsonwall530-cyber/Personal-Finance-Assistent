# Assistente de Finanças Pessoais

Aplicativo desktop de controle financeiro desenvolvido em Python, com interface gráfica em Tkinter e armazenamento de dados em SQLite.

## Sobre o projeto

O objetivo é facilitar o registro, a organização e o acompanhamento de movimentações financeiras.

O projeto foi desenvolvido como parte do meu aprendizado prático em programação Python, manipulação de dados e bancos de dados relacionais.

## Funcionalidades

- Cadastro de ganhos, gastos fixos e gastos variáveis.
- Edição e exclusão de movimentações financeiras.
- Organização de despesas por subcategorias.
- Consulta de movimentações por mês.
- Cadastro e gerenciamento de despesas recorrentes.
- Geração de movimentações mensais a partir de recorrências.
- Resumos mensais de receitas, despesas e balanço.
- Visualização de resultados financeiros ao longo do ano.

## Tecnologias utilizadas

- **Python:** linguagem principal de programação.
- **Tkinter:** desenvolvimento da interface gráfica.
- **SQLite:** armazenamento das informações financeiras.
- **SQL:** criação, consulta e manipulação dos registros.

## Como executar

1. Instale o Python 3.
2. Obtenha os arquivos do projeto.
3. Abra a pasta do aplicativo em um terminal.
4. Execute o comando `python main.py`.

O aplicativo cria automaticamente as tabelas necessárias no banco de dados SQLite.
